# 编辑页功能对照

折页以语雀的文档写作流程为参考。参考资料是[语雀产品介绍](https://www.yuque.com/about/groups)和一份[较早的语雀可视化编辑器功能说明](https://github.com/grasilife/yuque/blob/master/dive-into-yuque-editor.md)；后者不能代表语雀当前版本的完整功能。折页仍以本地 `.md` 文件为唯一正文格式。

| 写作场景 | 折页 0.5.0 | 边界 |
| --- | --- | --- |
| 快速插入 | 可视化编辑页的“插入”菜单提供 2×2、3×3、4×4 表格；源码分栏的空白行可输入 `/` 选择 Markdown 片段 | 源码分栏仍显示 Markdown 语法 |
| 顶部工具栏 | 标题层级、加粗、斜体、删除线、链接和“插入”菜单 | 可视化模式由 Tiptap 编辑，源码分栏由 CodeMirror 编辑 |
| 表格 | 可见单元格内直接输入、Tab 移动、拖动列宽、增删行列，并保存为 GFM Markdown 表格 | Markdown 不支持单元格合并与复杂样式，本版不提供这些不能无损保存的功能 |
| 快捷键 | Ctrl+B/I/K、Ctrl+Shift+X、Ctrl+Shift+7/8、Ctrl+Z/Y、Ctrl+F/H、Ctrl+S | 源码分栏支持 Ctrl+F/H；可视化模式查找会切到源码分栏 |
| 本地图片 | 文件选择、剪贴板粘贴、拖入窗口；外部图片复制到文档旁的 `assets/` | 文档需先保存；只接受常见图片格式且单张不超过 16 MB |
| 大纲 | 提取标题，可跳转编辑位置和阅读位置 | 标题以 Markdown 语法为准 |
| 阅读与写作 | 可视化编辑、源码分栏、预览；源码分栏双向滚动同步并记住比例；预览内查找、代码复制和图片放大 | 不含语雀的协作阅读状态 |
| 保存 | 本地草稿恢复、手动保存、外部修改冲突提醒 | 不提供云端历史版本或多人协作 |

语雀的评论、协作、知识库卡片、思维导图、流程图和在线附件依赖它的云端文档模型；本地 Markdown 无法无损保存这些内容，因此本版没有伪装成等价功能。后续若要支持公式或图表，应先确定可移植的 Markdown 语法和导出规则，再选择成熟渲染库。

阅读体验还参考了 [Moji 的本地 Markdown 阅读器](https://github.com/alexishida/moji)：在预览中查找、分栏滚动同步、代码复制和图片放大。折页保留 MyGO + WebView2 桌面外壳和现有 React Markdown 渲染链。
