# 0.5.0 验证记录

验证平台：Windows x64；Go 1.27.3；Node.js 24.19.0；pnpm 11.25.0；MyGO v0.6.3；React 19；WebView2。

## 已通过

- `pnpm install --frozen-lockfile --offline`：锁文件与包清单一致。
- `pnpm run build`：TypeScript 检查与 Vite 生产构建通过。
- `gofmt -l source`：无未格式化文件。
- `go test ./...`：应用与存储、内容模块测试通过。
- `go vet ./...`：通过。
- `go tool mygo build -platform windows/amd64`：生成可执行文件和 NSIS 安装程序。
- `scripts/smoke.ps1`：打包程序打开含空格的中文路径；第二次启动将文档交给原窗口，两份文件进入恢复会话；正常和窄窗口截图成功。空白行输入 `/` 后弹出格式菜单。
- 真实 WebView2 中验证预览内查找并高亮、跨加粗边界查找、代码块复制按钮可见、图片放大弹窗打开，以及长文档编辑与预览的双向滚动同步。
- 含中文文件名的图片文档验证了 WebView2 本地图片协议，预览图片实际显示。验证截图位于 `docs/screenshots`。
- 打包后的原生窗口插入 3×3 可视化表格，编辑单元格、增加一行，切到源码确认 Markdown 表格语法，再切回可视化编辑确认单元格还原。点击保存后，测试 `.md` 文件包含新增表格。
- 可视化编辑页的本地图片经现有 MyGO 图片协议正常显示。表格及图片截图保存在 `test-results/packaged-*/foldmark-table.png`。

自动测试覆盖 UTF-8 BOM / CRLF 保留、原子替换、外部修改和文件删除冲突、另存为、输入大小限制、文件夹扫描、草稿恢复、关闭保存决策、编辑修订号、文档排序、本地图片路径限制及 HTML 导出清理。新增图片导入测试覆盖外部图片复制、文档内图片复用、不同导入文件名、无效图片及剪贴板导入。打包验证覆盖真实 WebView2 页面加载、中文路径、第二实例转交和斜杠菜单弹出。

已查看真实窗口截图，确认浅色纸面、松绿色组件、中文排版、可视化表格、分栏与窄窗口布局；预览查找高亮、代码块工具栏、图片弹窗和长文档同步位置均已检查。分栏比例由现有 `react-resizable-panels` 的 `useDefaultLayout` 持久化。
